## 📌 Mini Project — Customer Segmentation Using K-Means

### **File Name:**  
**`Mini Project ML.py`**

### **Project Title:**  
**Customer Segmentation Using K-Means Clustering**

### **Dataset:**  
Mall Customers Dataset (Kaggle)

### **Purpose:**  
To segment customers into meaningful groups based on demographic attributes and spending behavior.  
This helps businesses understand customer patterns, personalize services, and develop targeted marketing strategies.

### **Key Steps Performed:**
- Data loading & preprocessing  
- Feature selection (Age, Annual Income, Spending Score, etc.)  
- Applying **K-Means clustering**  
- Finding optimal cluster count using the **Elbow Method**  
- Visualizing clusters with scatter plots  
- Interpreting customer segments

### **Outcome:**  
Successfully segmented customers into clusters revealing patterns such as:  
- High-spenders vs low-spenders  
- Age-based segmentation  
- Income & spending correlations
